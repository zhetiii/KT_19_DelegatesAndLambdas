# KT_19_DelegatesAndLambdas

# Вариант 1. Обработка чисел

List<int> numbers с произвольным набором положительных и отрицательных чисел.Лямбда-фильтр Func<int, bool>: оставляет только чётные числа.Лямбда-преобразование Func<int, int>: возводит число в квадрат.Два лямбда-действия Action<int>, объединённые через += в один многоадресный делегат: одно выводит результат на экран, второе сохраняет его в отдельный список.Конвейер: для каждого чётного числа вычислить квадрат и выполнить объединённое действие с результатом.

# Вариант 2. Обработка сообщений

List<string> messages с произвольным набором строк, включая пустые или слишком короткие.Лямбда-фильтр Func<string, bool>: оставляет только строки длиннее 3 символов.Лямбда-преобразование Func<string, string>: переводит строку в верхний регистр и добавляет префикс (например, "[LOG] ").Два лямбда-действия Action<string>, объединённые через += в один многоадресный делегат: одно выводит результат на экран, второе сохраняет его в отдельный список истории.Конвейер: для каждой подходящей строки выполнить преобразование и объединённое действие с результатом.
